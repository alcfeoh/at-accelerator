# AtAccelerator

Starter for the [Angular Accelerator](https://courses.angulartraining.com/course/angular-accelerator-program) TV Show Tracker exercises.

This project uses **Angular 21.1** and **TypeScript 5.9**. Unit tests run with **Karma**.

## Development server

```bash
npm install
ng serve
```

Open `http://localhost:4200/`.

## Build

```bash
ng build
```

## Tests

```bash
ng test
```

Runs unit tests with Karma.
